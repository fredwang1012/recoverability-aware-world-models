# CARLA results

Everything here came from CARLA 0.9.16 runs (physics profile `pp_381b4c6e55`). The `.md` summaries, figures and small JSON files are committed; the raw per-scene records (`<group>/*.jsonl`), run logs, the exported dataset and the videos stay local because of their size. Each summary was generated by the script named in [`../../../scripts/README.md`](../../../scripts/README.md). The overview is [`../../../docs/REPORT.md`](../../../docs/REPORT.md).

## Bring-up

| File | Contents |
| --- | --- |
| `runtime.json` | Server and client versions, map hash, world settings |
| `physics_profile.json`, `calibration.md` | Brake calibration: torque against measured deceleration at fixed tyre friction |
| `selftest.txt`, `determinism.md`, `timing.md` | Bring-up checks: lane keeping and braking, same-server repeats, step timing |

## Videos

`videos/index.md` lists the 36 recorded clips with each clip's outcome checked against the stored record. The uncompressed `.mp4` files (1.4 GB) are local only; the compressed copies are in [`docs/videos/`](../../../docs/videos/README.md). Rebuild with `scripts/carla_videos.py`, then `scripts/publish_videos.py`.

## Local-only folders

`dataset/` (E1 export), `old_pp_*` and `superseded_run*` (records from older physics profiles or superseded runs, kept for audit and never used by a summary).
