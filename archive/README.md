# archive

Early starter code from before the `mining/` package, kept for reference. Nothing here is used by the current pipeline or the tests.

| Folder | What it was |
| --- | --- |
| `starter_v1/` | First prototype (`mine_unrecoverable.py`): headless 2D mining on the team's highway-env two-lane scene, with a recoverability map and matched pairs |
| `starter_highwayenv/` | Second prototype (`mine_search.py`): random sampling and two search algorithms sharing one oracle and budget, with an algorithm comparison |
